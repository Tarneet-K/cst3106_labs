# Design System – Yatzy

## Color Palette
| Name | Hex | Usage |
|------|------|--------|
| Primary | #4F46E5 | Buttons & headings |
| Accent | #F59E0B | Highlight held dice |
| Background | #FAFAFA | Page background |
| Text | #1F2937 | Main text |
| Border | #E5E7EB | Dice outlines |

**Rationale:** Indigo + Amber = playful yet readable.

## Fonts
- Headings → Lilita One (fun, game-style)  
- Body → Inter (simple and clean)
