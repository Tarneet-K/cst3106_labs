# Yatzy – Game Design (Lab 05)

## Overview
Yatzy is a dice game played over multiple rounds. Each turn you roll up to three times, hold dice you want to keep, and aim for scoring combinations. This lab focuses on documenting your design system and creating mock-ups.

## Rules
- Roll five dice, up to three times per round  
- You can hold dice between rolls  
- After your last roll, choose one category to score  
- Each category can be used once  

## Design Goals
Clear, colorful, consistent layout using accessible colors and fonts.

## Files
- docs/design-system.md – color palette & fonts  
- docs/interaction-notes.md – layout & animations  
- assets/dice-sketch.png – dice visual  
- mockups/index.html + styles.css – static mock-ups
